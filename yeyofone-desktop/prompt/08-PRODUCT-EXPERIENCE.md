# Phases 34-35: product experience

Use the master rules. Execute only the requested phase.

## Phase 34 — UI refinement

Polish without changing SIP internals. Cover responsive windows, high DPI/scaling, themes, localization/RTL, keyboard/focus, screen readers, reduced motion, loading/empty/error/offline states and truthful controls. Preserve native window conventions per OS.

## Phase 35 — Compact call window

Provide an optional focused always-on-top call surface with clear identity/status, essential controls, multi-monitor positioning, restored bounds and reliable handoff to the main window. Avoid trapping focus or obscuring security prompts.

Exit gate: accessibility and keyboard audits, zoom/scaling, window restoration, multi-display and active-call journeys pass on supported systems.
